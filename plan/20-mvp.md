状态：`In progress`（开发期；A00/A01 已完成开发期交付，A01 实现与验证见 `99` 第 5.3 节，A03 数据库基础已完成开发期交付与设计复核，见 `99` 第5.4节；A04引擎已完成开发期交付（99 §5.5）；A02配置及Flag存储读取已交付，整包仍为部分交付。A00 未知许可遵守 DEC-045/046，不恢复已取消的本机版本化前置；正式门禁仍未通过）。

## 1. 范围

- 精确范围：`01` 中阶段为 MVP 的 149 个需求（`DEC-031` 新增 `AUTH-014`）。
- 前置：M0 Repository Ready。
- 公开上线前置：M0 Production Approved 和本阶段全部发布门禁。
- 不包含：P1-A、P1-B、P2、P2/Later、Later 功能启用。
- 验证分层（DEC-020）：开发期每次提交只执行最小集；各波次退出所列真实集成、安全、并发、性能与视觉验证统一在波次 E 硬化工作包集中执行并留存证据。

## 7. MVP 可启用 Flag

只有门禁通过并经发布审批后，才可逐项启用公开阅读、邀请注册、邮箱验证、主题、回复、附件、搜索、RSS、举报、客服和基础后台。

注册锁、邀请锁和只读模式必须随时可用。生产开启记录包含批准人、时间、环境、配置版本和关闭条件。

## 8. 必须关闭

- 完整积分、签到和任何用户自由转账。
- 私信、投票、悬赏、抽奖、红包和兑换码。
- 商家交易和商业活动。
- 开放 API、Webhook、桥接和 AI。
- 生产 JIT、临时提权和会话代理。

测试必须验证服务端路由不可达、配置不可开启和数据库持久化状态关闭。

## 9. Repository Ready 退出门禁

按 DEC-020 分两层执行：开发期每次提交过最小集；完整矩阵在统一硬化阶段（`WP-MVP-E01/E02/E04/E05`）集中执行并留存证据。

开发期最小集（每次提交）：

- [ ] 格式化、Clippy `-D warnings`、单元测试、SQLite 冒烟、`git diff --check` 与暂存区复核通过（`DEC-039`：不含独立构建步）。

统一硬化阶段（`WP-MVP-E01/E02/E04/E05`）：

- [ ] 149 个 MVP 需求中，非 `Blocked` 项全部达到符合事实的 `Implemented`，不存在“部分实现却标 Implemented”；`Blocked` 项逐条链接阻塞它的待决决策。`Verified` 不是发布候选的准入门槛（`DEC-039`），只在统一硬化阶段凭证据授予。
- [ ] 五条核心 E2E：游客阅读、邀请注册、发帖回复、举报处理、账号找回通过。
- [ ] 真实 PostgreSQL 默认和随机非默认前缀全套集成通过；SQLite 体验模式核心流程通过。
- [ ] Redis 原子性、清空/重建和故障降级通过。
- [ ] Outbox 多 Worker、重放、DLQ、sink 去重和副作用暂停通过。
- [ ] XSS、CSRF、SQL 注入、越权、枚举、SSRF、上传绕过、重放、限速和泄露测试通过。
- [ ] 关键 MVP 并发无重复消费、楼层冲突、重复处罚或重复通知。
- [ ] 容量数据集与 200 read/s、20 write/s 基线达到 p95 目标。
- [ ] WCAG 2.2 AA、六视口、明暗、键盘、无 JS、长文本和错误态通过。
- [ ] `05` 像素和几何差异门槛通过。
- [ ] 无未解决 Critical/High 代码、架构或安全问题。
