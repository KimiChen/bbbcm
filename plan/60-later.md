## 2. 范围

- P2/Later：14 个需求。

- 外部提醒桥接、API、OAuth 应用、机器人、Webhook、迁移/导入导出、AI 和自定义 CSS。

## 3. 工作包

### `WP-LATER-01` 外部提醒桥接

需求：`MSG-105`、`INTEG-101`。

Telegram、Discord 或邮件提醒严格继承内容权限；撤销连接和删除数据后不能继续投递。

### `WP-LATER-02` API 与 OAuth 应用

需求：`API-101/201/202`。

从只读 API 开始，按 scope、PAT/OAuth、配额、撤销、审计和开发者审核逐级开放。不能复用普通 Web 会话作为 API token。

### `WP-LATER-03` Webhook

需求：`WEBHOOK-101`。

签名、时间戳、防重放、目标验证、SSRF 防护、配额、退避、DLQ、密钥轮换和敏感字段裁剪。

### `WP-LATER-04` 数据迁移与程序化导出

需求：`API-102`。

全站迁移、批量导入导出和授权导出需要 schema 版本、校验、幂等、权限和审计。

### `WP-LATER-05` AI

需求：`AI-101` 至 `AI-103`、`AI-201` 至 `AI-204`。

只做用户确认的写作辅助、摘要、审核提示和显式 `@机器人`。记录提示词/模型版本、来源、成本和拒答，不让模型直接执行高危命令。

### `WP-LATER-06` 自定义 CSS

需求：`PREF-201`。

`PREF-201` 需要独立威胁模型、严格作用域、内容安全策略、导入限制和一键关闭，不能影响其他用户或管理页面。
