# WP-MVP-E01 HTTP/E2E 行为矩阵（2026-09-07）

`90` §5「HTTP/E2E」列了四组检查。本文件覆盖其中**不依赖尚未交付路由**的部分，
并明确标注未覆盖项——不得据本文件宣称 E2E 全路径完成。

## 覆盖范围的前提

本次运行的是 SQLite 体验模式且内容/管理服务未装配，因此 `/t/{id}`、`/forums/*`、
`/search`、`/manage/*` 一律失败关闭（404）。可驱动的稳定面是 `05` 冻结的
`/__fixtures/a00/*` 十四页——它们正是 A 级页面的隔离夹具。

## 一、状态矩阵（HTTP 层）

| 路径 | 状态 | 说明 |
|---|---|---|
| `/health` | 200 | 成功 |
| `/__fixtures/a00/home` | 200 | 成功 |
| `/__fixtures/a00/empty` | 200 | **空态**可达 |
| `/__fixtures/a00/error` | 200 | **错误态**可达 |
| `/manage`、`/manage/cases` | 404 | 未认证不得进入，且不泄露结构 |
| `/t/999999`、`/forums/nonexistent` | 404 | 不存在 |
| `/assets/../../etc/passwd` | 404 | 路径穿越被拒 |
| `/__fixtures/a00/nosuchpage`、`/does-not-exist` | 404 | 未注册路由 |

「冲突」「过期」「依赖失败」三类状态未在此矩阵覆盖：前两者需真实业务写入路径，
后者已由 `apps/web/src/security_tests.rs` 在后端未装配状态下单独验证。

## 二、浏览器行为：刷新、返回、重试

在真实浏览器中走完整序列，每步比对路径、标题、激活导航项与正文长度：

| 步骤 | 路径 | 标题 | 激活项 | 正文长度 |
|---|---|---|---|---|
| 进入首页 | `/home` | 最新回复 · 草莓论坛 | 最新回复 | 1140 |
| 跳转到置顶 | `/pinned` | 置顶主题 · 草莓论坛 | 置顶 | 1134 |
| 浏览器返回 | `/home` | 最新回复 · 草莓论坛 | 最新回复 | 1140 |
| 刷新 | `/home` | 最新回复 · 草莓论坛 | 最新回复 | 1140 |

返回后四项**完全恢复**到进入时的状态，刷新后不变。

**重试同一 GET**：连续加载 `/topic` 两次，快照逐字节相同（`identical: true`）。
GET 幂等，重试不产生副作用。

## 三、多标签页隔离

两个独立上下文分别加载 `/home?theme=light` 与 `/topic?theme=dark`：

- 各自 `data-theme` 与实际背景色不同（`rgb(247,248,250)` vs `rgb(13,14,20)`）；
- 在 A 中跳转到 `/featured` 后，B 的路径、主题、标题、背景色**纹丝不动**
  （`bIsolated: true`）。

## 四、JavaScript 开启／关闭

**页面的 `<script>` 数量为 0。** 这不是「JS 可选」，而是这些页面**根本不用 JS**：

- 无 JS 时完整可用（已用 `curl` 取原始 HTML 验证，主体内容完整、无「请启用
  JavaScript」占位）；
- 有 JS 时行为完全相同，因为没有脚本可执行；
- 外部主机资源数量为 **0**，符合 `AGENTS.md` 「禁止热链 `sb.sb` 的 CSS、字体、
  脚本、图片和 API」。

主题切换靠 SSR + URL 参数实现，不依赖客户端脚本。

## 五、移动真实设备模拟

375×812、移动 UA、5 触摸点、`pointer: coarse`、`hover: none`：

| 项 | 结果 |
|---|---|
| 横向溢出 | 0 |
| 移动导航切换 | 生效（`.mobile-menu-link` / `.mobile-forum-link` 出现） |
| 脚本数 | 0 |
| 正文完整 | 是 |

这与此前 iframe 宽度模拟的结论一致，但更强：设备级模拟下 `pointer`/`hover`
特性查询也按触摸设备求值，不只是媒体查询宽度分支。
