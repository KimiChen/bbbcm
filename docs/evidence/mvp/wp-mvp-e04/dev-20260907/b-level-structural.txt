# WP-MVP-E01／E04 浏览器结构化检查（B 级，2026-09-07）

`05` 第 6 节把页面分两级：**A 级**适用第 10 节的像素与几何阈值，**B 级只做结构级
检查**，检查项为「无横向溢出、触控目标不小于 44px、对比度达标、键盘可达、
无 JavaScript 可用、错误态可达」。

本次执行的是**结构级检查**，它不依赖字体渲染基准，因此不需要 `05` 规定的固定
浏览器/字体/缩放环境。**A 级的像素与几何比对仍未执行**，本文件不构成视觉基准，
也不得据此宣称 `WP-MVP-E04` 完成。

## 方法

- 夹具：`/__fixtures/a00/{page}` 全部 14 页（`05` 冻结的稳定夹具）。
- 视口：`90` §5 规定的 1440 / 1024 / 768 / 760 / 390 / 320px。
- 主题：light 全量；dark 抽查 1440 与 390。
- 测量：在与目标视口等宽的 iframe 中真实布局后读取几何值，媒体查询按 iframe
  视口宽度生效。共 154 个「页面 × 视口 × 主题」组合。
- 无 JavaScript 项用 `curl` 取原始 HTML，完全不执行脚本。

## 结果

| 检查项 | 结果 |
|---|---|
| 无横向溢出 | **通过，0/154**。六个视口与两种主题下 `scrollWidth` 均未超出 `clientWidth`。 |
| 键盘可达 | **通过**。无任何交互元素带 `tabindex="-1"`。 |
| 无 JavaScript 可用 | **通过**。九个代表页 SSR 输出均含完整主体内容，无「请启用 JavaScript」占位。 |
| 错误态可达 | **通过**。`error` 夹具在全部视口正常渲染。 |
| 触控目标 ≥ 44px | **不达标**，见下。 |
| 对比度 WCAG 2.2 AA | **不达标**，见下。 |

### 触控目标

已按 WCAG 2.5.8 的**内联豁免**排除正文句子中的链接（1440px 下仅 3 处属此类）。
其余为真实的非内联交互控件：

| 控件 | 实测尺寸 |
|---|---|
| `a.brand` | 83 × 34 |
| `a.mobile-forum-link` | 33px 高（390/320 视口） |
| `a.mobile-menu-link` | 39px 高 |
| `input.search-input` | 37px 高 |
| `button.search-btn` | 32 × 26 |
| `a.nav-mine` | 46 × 37 |
| `a.tab` | 36px 宽 |

全部 14 页、全部 6 个视口均存在。移动视口（390/320）同样不达标——触控在那里最关键。

### 对比度

light 主题：

| 元素 | 实测 | 要求 |
|---|---|---|
| `a.post-title` @15px | 3.19 | 4.5 |
| `span.footer-version` @11.5px | 2.95 | 4.5 |
| `span.post-user-group` @11px | 3.84 / 3.91 | 4.5 |

dark 主题：

| 元素 | 实测 | 要求 |
|---|---|---|
| `span.footer-version` @11.5px | 4.04 | 4.5 |
| `span.post-user-group` @11px | 3.91 | 4.5 |

背景色向上追溯到第一个非透明祖先后计算；直接读元素自身 `background-color`
会把多数元素判为 transparent，从而算出错误的高对比度。
