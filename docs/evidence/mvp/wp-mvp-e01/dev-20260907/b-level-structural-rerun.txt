# B 级结构化检查复跑：六项导航 + 对比度测量纠错（2026-09-07）

`DEC-068` 把导航从四项改成六项，动的正是 A00 冻结夹具的页头与移动版块条，
因此上一份 `b-level-structural.txt` 在导航区的结论失效，本文件是复跑记录。

复跑同时发现上一轮**对比度测量本身有缺陷**，`DEC-067` 的「全量达标」不成立。
详见第 3 节。

## 1. 无横向溢出：通过（0/112）

- 夹具：`/__fixtures/a00/{page}` 全部 14 页。
- 视口：1440 / 1024 / 768 / 760 / 390 / 320px。
- 主题：light 全量；dark 抽查 1440 与 390。共 112 个组合。
- 方法：等宽 iframe 内真实布局后读 `scrollWidth` 与 `clientWidth`，媒体查询按
  iframe 视口宽度生效；另逐元素找 `right > 视口宽` 的最外侧元素以便定位。

结果：**112 个组合全部无横向溢出**，每页主导航均为 6 项。

### 先作废了一次自己的空测量

第一次跑时页型列表里写了 `settings` 与 `rules`——这两个名字不在 `PAGES` 白名单里，
服务端按设计不回退，渲染出空文档。空文档当然不会溢出，那 16 个组合是**空测量**，
「0 溢出」当时不成立。已改用 `fixtures.rs` 中的真实 14 页重跑，并加了防空判定
（每个组合必须存在 `.brand` 且正文长度 > 50 才算数），复跑时未渲染数为 0。

## 2. 触控目标：AA 口径未变差，AAA 口径变差

390px light 全 14 页实测：

| 指标 | `DEC-067` 记录（四项导航） | 本次（六项导航） |
|---|---|---|
| 非内联交互目标 | 559 | **601** |
| < 44px（WCAG 2.5.5 AAA） | 505 | **561** |
| < 24px（WCAG 2.5.8 AA） | 192 | **192** |
| 内联豁免 | 3 | 3 |

新增目标的实测尺寸解释了这个结果：

| 控件 | 尺寸 | 出现次数 |
|---|---|---|
| `a.forum-link` | 0 × 0（390px 下桌面导航隐藏） | 84 |
| `a.mobile-forum-link` | 48 × 33 / 34 × 33 | 49 |
| `a.mobile-menu-link` | 267 × 39 | 140 |

两个新版块带来的都是高 33–39px 的链接：**低于 44px 但高于 24px**。因此 AAA 口径
的不达标数上升，AA 口径的 192 一项未变。

这不改变 `DEC-067` 留下的待裁决项——`05` §6 写 44px（相当于 AAA），`90` §5 要求
的 WCAG 2.2 **AA** 对应 2.5.8 的 24px 且允许间距替代。门槛取哪一个仍待裁决。

## 3. 对比度：`DEC-067` 的「全量达标」不成立，已定位并修正

复跑量到 6 项失败，全部是 light 主题下的 `a.post-title`，比值 4.32（要求 4.5）。
逐层查证后确认**不是回归，是上一轮的测量方法错了**：

**测量端两处缺陷**

1. 颜色解析只认 `rgb()/rgba()`。置顶行的高亮是
   `color(srgb 1 0.956863 0.768627 / 0.45)`，其分量在 0–1 区间，被当成 0–255 读，
   算出来是近黑色。
2. 没有对半透明背景做 alpha 合成——直接把这层高亮当作不透明底色。

两者叠加，把一层浅黄高亮算成近黑背景，于是深橙文字得出**虚高**的比值。

**同一个缺陷进了修复值**

`a11y.css` 原注释写的是「`#d97706` on `#ffffff` = 3.19 -> `#b26205` = 4.54」。
背景根本不是 `#ffffff`：置顶行 `li.post-item.topic-pinned` 的高亮压在
`ul.post-list` 的白底上，合成后是 **`#fffae4`**。按真实底色复测，`#b26205`
只有 **4.32**，仍不达标；那个 4.54 是用错误背景解出来的。

**修正**

按合成底色 `#fffae4` 重解，沿明度轴取第一个达到 4.5 的颜色，保留原色相与饱和度：
`#b26205` → **`#ad5f05`**，实测 **4.542**。深色主题的置顶标题合成底色为
`rgb(32,29,26)`，实测 5.265，本就达标，未改。

**修正后复测**

14 页 × 两主题 @390px，共 28 个组合、**2782 个文本节点**，未渲染数 0，
**对比度失败项 0**。解析器现同时支持 `rgb()/rgba()` 与 `color(srgb r g b / a)`，
并沿祖先链把 alpha 合成到不透明底色后再计算。

## 未覆盖

A 级像素与几何比对仍未执行，且导航改为六项后，此前基于四项导航采集的结构化
数据在导航区不再可比，`05` §10 的基准需在新导航上重拍。本文件是结构级检查，
不构成视觉基准。
