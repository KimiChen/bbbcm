# A00 参考页面采集

依据 `plan/05-visual-brand-spec.md` 与 `DEC-044`，后续采集默认保留参考页面原始截图，由项目所有者后续处理。本轮采集限定与资产登记顺序已按 `DEC-046` 调整；下文描述现有脚本的实际行为。该入口只用于 A00 开发观察，不生成已批准的视觉基准，也不代表 E04 门禁通过。

在仓库根目录执行，使用现有本机 Chrome `127.0.0.1:9222`：

```bash
node scripts/a00-capture.mjs
node scripts/a00-capture.mjs --raw
```

两条命令等价。原始 PNG、结构/计算值 JSON 和 manifest 固定写入 `docs/evidence/local/a00-redo/reference/`。该目录受 `.gitignore` 的 `/docs/evidence/local/` 规则保护；脚本启动前会检查此规则有效，失效则拒绝采集。输出路径不能通过命令行覆盖，原始截图不得直接提交到公开仓库。原始模式保留图片与原始可见内容，不添加遮罩。

需要重跑既有脱敏证据时，必须显式选择：

```bash
node scripts/a00-capture.mjs --sanitized
```

此模式沿用截图前遮罩与图片/媒体阻断，固定写入 `docs/visual/a00/reference/`，仅供以后明确需要时使用。本轮已生成的脱敏 PNG 按用户后续指令移除，重新采集的原始 PNG 只留本地；公开结构/计算值 JSON 已同步本轮原始重采结果；公开 manifest 只保存本地截图入口与哈希，不包含截图本体。参考站内容会变化，重跑结果不是旧截图的确定性副本。

现有脚本的两种模式均创建独立浏览器上下文，采集结束关闭该上下文；上下文选择属于当前实现方式。脚本阻断参考站脚本和追踪请求，导航和字体就绪均有超时检查；主题设置、动画关闭和固定视口用于稳定开发观察。

现有脚本导出标签/类名结构、设计 token、计算值、几何、HTTP 状态及错误码。主题链接在内存中用于导航，manifest 的主题路径使用 `[public-id-redacted]`；找回密码页面从登录页实际链接取得。manifest 记录截图 SHA-256 及对应观察 JSON 路径；未经后处理与公开适用性复核的原始截图不能替代正式批准证据。

本轮另以当前公开首页的作者链接在匿名上下文中补采个人主页1440/390原图，位于同级 `profile/`；安全索引见 `profile-observation.json`。实际账号路径只用于内存导航，未写入公开记录。这两张补采图不属于上述脚本的15页默认清单。
